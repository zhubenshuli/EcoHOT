【经济、投资与大宗商品领域专业术语规则 — 本平台聚焦宏观经济、A股投资、大宗商品（黄金/石油/基础资源价格）与金融市场，严格遵守】

1. 歧义默认值：以下词在中文语境有歧义，一律按经济、金融、投资与大宗商品含义翻译：
   - Fed = 美联储（美国联邦储备系统）
   - PBOC = 中国人民银行
   - ECB = 欧洲央行
   - OPEC / OPEC+ = 欧佩克 / 石油输出国组织及其盟友
   - SSE = 上海证券交易所（上交所）
   - SZSE = 深圳证券交易所（深交所）
   - BSE = 北京证券交易所（北交所）
   - SHFE = 上海期货交易所（上期所）
   - SGE = 上海黄金交易所（上金所）
   - Rate cut / Rate hike = 降息 / 加息
   - Basis point / bps = 基点
   - Yield = 收益率（债券/投资）
   - Inflation = 通货膨胀 / 通胀
   - Deflation = 通货紧缩 / 通缩
   - Balance Sheet = 资产负债表（美联储缩表为 quantitative tightening / 缩表）
   - Quantitative Easing (QE) = 量化宽松
   - Treasury / Treasuries = 美国国债 / 美债
   - Sovereign Debt = 主权债务
   - Trade Deficit / Surplus = 贸易逆差 / 顺差
   - Tariffs = 关税
   - Commodity / Commodities = 大宗商品
   - Spot Gold / COMEX Gold = 现货黄金（伦敦金）/ COMEX黄金期货
   - WTI / Brent Crude = WTI原油 / 布伦特原油
   - Base Metals / Industrial Metals = 基础工业金属 / 基础资源
   - Lithium Carbonate = 碳酸锂
   - Northbound Funds = 北向资金 / 陆股通资金
   - Margin Financing and Securities Lending = 融资融券（两融）

2. 以下国际专有名词一律保留标准英文缩写或权威规范译名：
   - 国际组织与机构：IMF（国际货币基金组织）/ World Bank（世界银行）/ BIS（国际清算银行）/ WTO（世贸组织）/ OECD（经合组织）/ OPEC（欧佩克）
   - 经济与市场指标缩写：GDP / CPI / PPI / PMI / PCE / Core PCE / Non-farm Payrolls（非农）
   - 证券与金融工具：A股 / IPO / LPR / MLF / ETF / REITs / PE（市盈率）/ PB（市净率）/ ROE（净资产收益率）/ VC / CDS / LIBOR / SOFR

3. 数字与度量单位严格保持真实准确：
   - 百分比、基点（如 25 bps / 25个基点）、金额（如 $50B、1000亿元）、汇率、金价（如 $2700/盎司、620元/克）、油价（如 $75/桶）、基础资源价格（如 铜 78000元/吨、碳酸锂 7.5万元/吨）一字不改保留精确阿拉伯数字与单位。
   - 不把精确数字模糊化为“数十亿”“大幅增长”“暴涨暴跌”。
